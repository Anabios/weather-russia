# 🇷🇺 Weather Cards Russia (Погода в городах РФ)

An interactive, responsive single-page web dashboard showcasing daily and 24-hour weather forecasts across the five largest metropolitan hubs in Russia: **Moscow, Saint Petersburg, Novosibirsk, Yekaterinburg, and Kazan**.

Built with modern vanilla web technologies, dynamic SVG landmark graphics, custom Canvas atmosphere particle physics, and an interactive microclimate inspector for prominent high-altitude landmarks.

---

## ✨ Features

- **Iconic Architectural Silhouettes:** Each city includes detailed, interactive SVG vector artwork with hover states and clickable architectural landmarks.
- **Microclimate Inspector:** Clickable elements (e.g., Moscow-City towers, Spasskaya Tower, Bugrinsky Bridge) display real-time altitude metrics, observation deck conditions, and local wind tunnel data.
- **24-Hour Interactive Timeline:** Smooth slider controls to inspect hourly temperature shifts, precipitation, barometric pressure, humidity levels, and compass wind directions from 00:00 to 23:00.
- **Dayparts Overview:** Quick-select panels for Night, Morning, Day, and Evening.
- **Atmospheric Canvas FX:** Real-time background simulation of rain, wet snow, autumn mist, and ambient light particles tailored to each city's climate profile.
- **Glassmorphism UI:** Clean translucent panels, backdrop filters, and adaptive color palettes built strictly with pure CSS/vanilla JavaScript (no heavy runtime dependencies).

## 🏙️ Featured Cities & Landmarks

1. **Moscow (`+3°C`)**
   - Moscow-City Skyscrapers (*Federation Tower, Evolution Tower*) with 354m altitude microclimate data.
   - Spasskaya Tower & Ruby Star chimes.
   - Saint Basil's Cathedral onion domes.
2. **Saint Petersburg (`+4°C`)**
   - Palace Bridge raised bascules over the Neva River.
   - Peter and Paul Cathedral spire with the Golden Angel.
   - Saint Isaac's Cathedral dome.
3. **Novosibirsk (`-2°C`)**
   - Bugrinsky arched bridge over the Ob River.
   - NOVAT (Novosibirsk Opera and Ballet Theatre) grand dome.
   - Siberian pine silhouettes.
4. **Yekaterinburg (`-1°C`)**
   - Iset Tower (52 floors) and Vysotsky skyscraper panoramic desk.
   - Neo-Gothic Sevastyanov's House on the City Pond embankment.
5. **Kazan (`+2°C`)**
   - Qol Sharif Mosque minarets and turquoise domes.
   - Leaning Söyembikä Tower.
   - White-stone Kazan Kremlin fortress walls.

## 🚀 Quick Start

No installation or node modules required. Run directly in any modern web browser:

```bash
# Clone the repository
git clone [https://github.com/your-username/weather-russia.git](https://github.com/your-username/weather-russia.git)

# Navigate into the project folder
cd weather-russia

# Open index.html in your default browser
open index.html   # On macOS
start index.html  # On Windows
xdg-open index.html # On Linux
